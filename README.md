# 터미널 퀴즈 게임

Python으로 만든 콘솔 퀴즈 게임입니다. 메뉴에서 번호를 골라 퀴즈를 풀고, 새 퀴즈를 등록하고, 최고 점수를 확인할 수 있습니다. 프로그램을 종료해도 추가한 퀴즈와 최고 점수가 `state.json`에 저장되어 유지됩니다.

## 프로젝트 개요

- 언어: Python 3
- 실행 환경: 터미널(콘솔)
- 클래스 2개로 역할을 나눈 객체 지향 구조
  - `Quiz`: 퀴즈 1개(문제, 보기, 정답)를 표현
  - `QuizGame`: 메뉴, 게임 진행, 저장/불러오기를 관리
- 데이터는 JSON 파일(UTF-8)로 저장

## 퀴즈 주제 선정 이유

주제는 **상식**입니다. 누구나 바로 풀 수 있어서 게임의 흐름(출제, 입력, 채점, 점수)을 확인하기 쉽고, 퀴즈를 추가하는 기능을 테스트할 때도 문제를 떠올리기 부담이 없기 때문입니다. 기본 퀴즈는 5개이며, 실행 중에 더 추가할 수 있습니다.

## 실행 방법

1. Python 3이 설치되어 있어야 합니다. (`python --version`으로 확인)
2. 저장소를 내려받습니다.
   ```
   git clone https://github.com/cmc33sh-ux/quiz-game.git
   cd quiz-game
   ```
3. 실행합니다.
   ```
   python quiz_game.py
   ```
4. 메뉴에서 번호를 입력하고 Enter를 누릅니다.

## 기능 목록

| 메뉴 | 기능 | 설명 |
|---|---|---|
| 1 | 퀴즈 풀기 | 등록된 퀴즈를 차례로 출제하고 채점합니다. 끝나면 맞힌 개수를 보여주고, 최고 점수를 갱신합니다. |
| 2 | 퀴즈 추가 | 문제, 보기 4개, 정답 번호(1~4)를 입력해 새 퀴즈를 등록합니다. 잘못된 입력은 취소됩니다. |
| 3 | 퀴즈 목록 | 등록된 퀴즈의 문제를 번호와 함께 보여줍니다. |
| 4 | 점수 확인 | 저장된 최고 점수를 보여줍니다. |
| 5 | 종료 | 프로그램을 종료합니다. |

- 퀴즈를 추가하거나 최고 점수가 갱신되면 자동으로 `state.json`에 저장됩니다.
- 숫자가 아닌 값을 입력해도 프로그램이 멈추지 않도록 `try/except`로 처리했습니다.
- `state.json`이 없으면 기본 퀴즈로 시작하고, 파일이 손상되어 있으면 안내 후 기본 데이터로 시작합니다.

## 파일 구조

```
quiz-game/

├── .gitignore     # __pycache__/, state.json 제외
└── README.md
```

## 데이터 파일 설명 (state.json)

프로젝트 루트에 UTF-8로 저장되며, 처음 퀴즈를 추가하거나 최고 점수를 갱신할 때 만들어집니다. 사용자별 진행 데이터이므로 `.gitignore`에 등록해 저장소에는 올리지 않습니다.

```json
{
  "best_score": 5,
  "quizzes": [
    {
      "question": "대한민국의 수도는?",
      "choices": ["부산", "서울", "대구", "인천"],
      "answer": 2
    }
  ]
}
```

| 키 | 타입 | 설명 |
|---|---|---|
| `best_score` | int | 지금까지의 최고 점수(맞힌 개수) |
| `quizzes` | list | 퀴즈 목록 |
| `question` | str | 문제 |
| `choices` | list | 보기 목록 |
| `answer` | int | 정답 번호(1부터 시작) |
